1. INTRODUCCIÓN
================================================================================

Este proyecto consiste en el desarrollo de una plataforma web de e-commerce 
completa para "Yogurt Artesanal San Francisco", un emprendimiento familiar 
dedicado a la producción y comercialización de productos lácteos artesanales.

El sistema permite gestionar de manera integral las operaciones comerciales 
del negocio, desde la presentación de productos hasta la gestión de pedidos 
y administración del inventario.

NOTA: Este es un proyecto académico y familiar que actualmente se encuentra 
en fase de desarrollo, no está operacional en producción.

================================================================================
2. DESCRIPCIÓN DEL PROYECTO
================================================================================

2.1. Objetivo Principal
-----------------------
Desarrollar una solución tecnológica completa que permita a Yogurt Artesanal 
San Francisco:

- Presentar su catálogo de productos de manera atractiva y profesional
- Gestionar pedidos de manera eficiente
- Administrar inventario, usuarios y promociones

--------------------------
El sistema cubre las siguientes áreas funcionales:

✓ Gestión de productos y categorías
✓ Carrito de compras interactivo

3. TECNOLOGÍAS UTILIZADAS
================================================================================

3.1. Backend (Servidor)
------------------------
- PHP 7.4+: Lenguaje de programación del lado del servidor
- MySQL: Base de datos relacional para almacenamiento de información
- Arquitectura MVC (Modelo-Vista-Controlador): Para organización del código

3.2. Frontend (Interfaz de Usuario)
------------------------------------
- HTML5: Estructura de las páginas
- CSS3: Estilos y diseño responsive
- JavaScript: Interactividad y funcionalidades dinámicas
- Bootstrap 5: Framework CSS para diseño responsive
- Font Awesome: Iconografía
- SweetAlert2: Alertas y notificaciones modernas
- DataTables: Tablas interactivas en el panel de administración

3.3. Herramientas y Librerías
-------------------------------
- PDO (PHP Data Objects): Para conexión segura a la base de datos
- jQuery: Simplificación de JavaScript
- Google Fonts (Poppins): Tipografía moderna

5. ESTRUCTURA DEL PROYECTO
================================================================================

El proyecto sigue una arquitectura MVC (Modelo-Vista-Controlador) que 
facilita el mantenimiento y la escalabilidad:

📁 controllers/
   - Gestiona la lógica de negocio y el flujo de la aplicación
   - Ejemplos: CartController, AdminController, ProductController

📁 models/
   - Representa los datos y la lógica de acceso a la base de datos
   - Ejemplos: Product, Order, User, Cart

📁 views/
   - Contiene las plantillas HTML y la presentación
   - Organizado por módulos: admin, cart, checkout, products, etc.

📁 config/
   - Archivos de configuración
   - Conexión a base de datos
   - Configuraciones generales

📁 assets/
   - Recursos estáticos (imágenes, CSS, JavaScript)

6. FUNCIONALIDADES DESTACADAS
================================================================================

6.1. Sistema de Personalización de Productos
--------------------------------------------
Permite a los clientes crear productos personalizados seleccionando:
- Sabor del yogurt
- Tipo de endulzante
- Nivel de dulzor
- Tamaño del producto
- Opciones especiales (harinas alternativas, semillas, frutos secos)

6.2. Sistema de Descuentos Inteligente
---------------------------------------
- Descuento por envases devueltos ($2.000 por envase)
- Códigos promocionales manuales
- Promociones automáticas (15% primera compra)
- Promociones especiales (cumpleaños)
- Cálculo automático de descuentos combinados

6.3. Gestión de Estados de Pedidos
-----------------------------------
Sistema completo de seguimiento:
- Pendiente → Confirmado → Preparando → Enviado → Entregado
- Estados finales (Entregado/Cancelado) se ordenan automáticamente al final
- Notificaciones visuales con badges de colores

6.4. Interfaz Responsive
-------------------------
Diseño completamente adaptable a:
- Dispositivos móviles
- Tablets
- Computadoras de escritorio
- Diferentes tamaños de pantalla

6.5. Integración con WhatsApp
------------------------------
Botón flotante que permite contactar directamente por WhatsApp con 
información del pedido prellenada.
